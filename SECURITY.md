## Private reporting

Use the **Report a vulnerability** button of the repository Security tab (GitHub private vulnerability reporting). Do not open a public issue for an undisclosed vulnerability.

Include the affected commit or image digest, package versions, impact, reproduction steps and sanitized logs.

## Supported state

Security fixes target the current default branch and the newest artifacts produced from it. There is no versioned long-term-support channel; older images should be treated as unsupported.

## Security boundaries

- Images inherit the boot chain, installer, APT trust and image-signing boundaries from `debian-bootc`.
- Packages built by this repository run with host privileges.
- Privileged CI jobs must not execute untrusted contribution code with release credentials; the `PIPELINE_PAT` secret is scoped to the secrets and Actions permissions of the repositories it is granted on.

Supply-chain bypasses, credential exposure and privilege escalation introduced by project code are in scope.
