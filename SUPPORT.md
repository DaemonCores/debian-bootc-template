Support is provided through GitHub issues on a best-effort basis.

## Before opening an issue

Read the [README](README.md) and the [wiki](../../wiki), search existing issues, and include:

- image digest or commit;
- installation method;
- hardware or VM configuration;
- failed units, journal excerpts and reproduction steps.

The project does not provide paid support or response-time guarantees. Report security issues privately according to [SECURITY.md](SECURITY.md).
